## Sales-Inventory_Analytics_PowerBI_dashboard
This project presents an interactive PowerBI dashboard designed to analyze sales performance, customers behavior, products trends and inventory management. The dashboard is built using data from a PostgreSQL database and provides insights to support data driven decision making.

#  Tools and Technologies used in this project
1. PowerBI: For Data analysis, modelling, Dax operations, visualization and dashboard creation
2. PostgreSQL: Database management
3. Dbeaver: Database administration
4. SQL:For querying the PostgreSQL database

# Dataset Description
The dataset contains four tables that are connected using primary and secondary keys. The tables include;
1. Customers table: contains customers details
2. Products table: has products information,categories and pricing
3. Sales table: contains transaction records, quantities sold and revenue
4. Inventory table: tracks stock levels for each product

# Key Insights
1._**Sales Performance**_:
    There is a steady steady distribution of sales across months with noticeables peaks (highest sales) recorded in August 2023 and October 2023         and lowest sales recorded in November 2023.
    The Total sales Revenue is **8.13K**.
    
2._**Product Performance**_:
    Smartphones, Smart Tvs and Refrigerators had the highest sales and contributed to slightly above **50%** of the Total Revenue.
    The Electronics product category had the highest sales contributing to **66.13%** of the Total Revenue, followed by Appliances contributing to      **24.34%** and finally Accessories contributing to **9.53%** of the Total Revenue.
    
3._**Customer Insights**_:
    Customers with the Silver membership status contributed to **57.22%** of the Total Revenue, followed by by the Bronze with **35.4%** then Gold      with **7.38%**.
    
4._**Inventory insights**_:
    The total inventory stock value is 436.69K with Smartphones having the highest stock amount(**119,998.50**) followed by Laptops(**49,999.50**)      then refrigerators(**48,000**).
    Total stock quantity is **1675** products.

# Business Recommendations
Focus on high performing products(especially Electronics) to maximize revenue.

Introduce targeted promotions for low performing or overstocked products.

Introduce or strengthen loyalty programs to retain high value customers.

Optimize inventory management by aligning stock quantities with sales demand trends.
